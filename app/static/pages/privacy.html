Privacy Policy

Short version: MarkMute has no sign-up, no analytics and no tracking cookies. Core cleaning is local to the server you (or your host) run. This page describes exactly what data touches our systems and what you can configure.

1. Who we are

MarkMute (the "Service") is a product of Aptenox (aptenox.com). Contact: hello@aptenox.com.

2. Data we process

  • Text you paste and files you upload (PNG, JPEG, WebP, SVG, PDF, DOCX, ODT, HTML, MD, TXT) are processed to detect and remove watermarks, metadata and invisible characters.
  • Preferences: your light/dark theme choice is stored on your own device in your browser's local storage (key mm-theme). It is never sent to us.
  • Server logs: the hosting operator's standard request logs (IP address, user agent, requested URL) may be recorded for security and operations, as with any web server.

We do not use cookies for advertising or social media. We do not run analytics or tracking pixels. We do not sell or share personal data.

3. Where cleaning happens

All detection and cleaning (text scanning, metadata stripping, C2PA removal, SynthID scoring, CtrlRegen pixel removal) runs on the server instance running MarkMute — your own deployment or a hosting account you control. Your content is not sent to Aptenox or any third party for these operations.

4. Storage and retention of uploads

Uploaded files are stored temporarily on the server in an uploads/ directory (raw copies) plus a cleaned/ directory for results you download. Files are retained until removed by the operator or the storage is cleaned; the Service provides download links but no indefinite retention promise. Process only content you are allowed to store. If you run the Service yourself, retention is fully under your control.

5. Optional LLM rewrite

The Rewrite feature is off by default (it prints a prompt without calling any model). If you or your operator configure an LLM backend (Ollama locally, or an OpenAI-compatible provider), the text you paste may be sent to that provider. The browser asks for confirmation before any remote rewrite. Backend choice, API keys and provider are configured by the operator; see the supplied configuration options (e.g. OLLAMA_HOST, OpenAI-compatible base URL). If you do not want text sent anywhere, keep the default "print-prompt" mode.

6. Cookies and local storage

We set no functional cookies on the website. The only browser storage used is local storage for your theme preference, which never leaves your device. If your browser blocks local storage, the app still works using your system's color-scheme preference.

7. Security

We follow standard security practices: secrets (API keys) are read from server-side environment configuration, not from the browser; uploads are size-limited (256 MiB); and the API can be locked down with an API key where supported by the deployment.

8. Your rights

Depending on your jurisdiction (e.g. GDPR), you may have rights to access, correct or delete personal data we hold, or to complain to a supervisory authority. Since we hold no account data, these requests typically concern your own deployment's server logs and uploads — your operator can delete them at any time. Questions: hello@aptenox.com.

9. Changes to this policy

We may update this policy; the effective date at the top reflects the latest revision. Material changes will be highlighted on this page.
