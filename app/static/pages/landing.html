Frequently asked questions

What watermark types does MarkMute remove?

Invisible Unicode characters (zero-width spaces, joiners, bidi controls, variation selectors, tag characters), space homoglyphs, EXIF/XMP metadata, embedded thumbnails, C2PA manifests, and — on capable hardware — SynthID signals and pixel watermarks via CtrlRegen.

Is detection-based removal 100% reliable?

No — and we say so honestly. MarkMute is best-effort and verifiable: it reports what was found and removed, and explicitly warns when residual signals remain. If a C2PA chunk survives, you'll see it flagged.

Does MarkMute send my text or files anywhere?

No, not by default. Core cleaning runs using your own server infrastructure. The only exception is the optional Rewrite feature: it sends text to an LLM only if you explicitly configure an Ollama or OpenAI-compatible backend, and it asks for confirmation first.

Which file formats are supported?

Text: anything you paste. Files: PNG, JPEG, WebP, SVG, PDF, DOCX, ODT, HTML, MD, TXT up to 256 MiB. Some image-only tools (SynthID scoring, CtrlRegen removal) apply to PNG, JPEG and WebP.

Is MarkMute free? Is a sign-up needed?

Yes, MarkMute is free and needs no sign-up. It is a product by Aptenox.
